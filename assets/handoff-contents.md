# 渡す一式の中身（宛先ごとの正本）

**受け取る側が要るものだけを渡す。**迷ったら足すのではなく、
**受け取る側の手順書に「要る」と書いてあるか**で決める。

**余計なものを渡すと、受け取る側に「どれが正本か」の判断を押しつける。**
実績として、段階3へ渡すときに不要なものまで並べた。

## 置き場所

**`<案件>/out/latest/handoff/` のフォルダ1つ。**メモはその中の `HANDOFF.md`。
（1枚のファイルだけを渡す形はやめた。画像を含むと複数になる）

## 宛先ごとの表

| 渡すもの | pptx 化（段階3） | 別テンプレへの載せ替え | 台本づくり |
|---|---|---|---|
| スライドの HTML（**1ファイルに全枚でも、枚ごとに分かれていてもよい**） | **必須** | **必須** | **必須** |
| `print.html`（連結したもの） | **枚が分かれているときだけ必須** | 同じ | 不要 |
| HTML が参照する**案件固有の画像**（写真・現場の図） | **必須** | **必須** | 不要 |
| **テンプレート由来の画像**（ロゴ・共通素材） | **渡さない。**受け取る側が手元のテンプレから使う | 同じ | 不要 |
| px→pt 係数（HTML の `<meta>`、または `HANDOFF.md` に明記） | **必須** | 任意 | 不要 |
| `HANDOFF.md`（テンプレ名・係数・既知の不備・正本の指紋） | **必須** | **必須** | **必須** |
| テンプレート一式 | **任意**（相手が持っていれば同梱せず、指紋の一致を確かめる） | **必須** | 不要 |
| 用語台帳・数値台帳 | **渡さない** | **渡さない** | **必須**（台本の照合に使う） |
| 図版の判定表（`visual-review.md`） | **渡さない** | **渡さない** | 不要 |
| 台本（`script.md`） | **渡さない** | **渡さない** | （これが成果物） |
| 運用の台帳（`feedback.md` 等） | **渡さない** | **渡さない** | **渡さない** |

**「渡さない」は、隠すためではない。**受け取る側の担当ではないものを混ぜると、
**直す場所を間違える**（pptx 側を直す、台帳を書き換える）。

**どれが案件固有かの見分け方。**渡す側は**手元に実体がある画像だけ**を渡す。
無いものは相手のテンプレにある前提で、`HANDOFF.md` に
「参照しているが同梱していない画像」として一覧を書く。

## 機械で確かめる

```bash
python3 scripts/handoff.py <テンプレ> --for deck \
    --source <案件>/out/latest/*.html -o <案件>/out/latest/handoff/HANDOFF.md
```

**必須が欠けていれば異常終了する。**「渡さない」に当たるものが混ざっていれば指摘する。
**何を何件渡したかの一覧を出す**ので、報告にそのまま貼る。

**渡した後に正本を直したら、一式は古い。**`--stale` で確かめてから渡す。
