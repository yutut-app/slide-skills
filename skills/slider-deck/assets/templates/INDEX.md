# テンプレート索引

伝えたい内容の性質から、使うテンプレートを選ぶ。**選べないときは、そのスライドが
必要かどうかを先に疑う。**

すべて 1テンプレ = 1ファイル。Excel は1シート、PowerPoint は1スライド（16:9）。
使い方と注意は、Excel はシート内の「使い方」欄、PowerPoint はスピーカーノートに入れてある。
**PowerPoint のノートは資料に残さない。** 中身を埋めたら消す。

### 資料テンプレート（このフォルダの外）

資料テンプレートは**リポジトリ直下の `assets/templates/deck/`** にある。
`slider-craft` と `slider-reskin` の2スキルが同じ場所を見るため、
スキルの中には置かない。**2箇所に置くと必ず食い違う。**

置き方・調べ方・追加は `slider-reskin/references/20_templates.md` を読む。

できあがった資料を別のテンプレートに載せ替えるのは `slider-reskin` の役目。
**本スキルでは行わない。**

## 共通の作法

- **配色は4色まで。** 濃紺 `1F4E79`（主役）／青 `4472C4`（副役）／グレー `808080`（比較対象）／
  赤 `C00000`（基準線・逸脱の指摘のみ）。**赤を装飾に使わない**。
  **これは資料テンプレートが無いときの既定値。**あるならテーマの配色に合わせる
- **強調は1つ。** 全部を色分けすると、どれが主張か分からなくなる
- **文体は部位で固定する。** 見出しは体言止め、メッセージラインは言い切り、
  箇条書きは体言止めで統一。句点は付けない
- **数値の軸は0から始める。** 始めない場合は軸か注記に明示する
- **推測値で図を作らない。** 件数が足りないときは作図せず、その旨を伝える

## 再生成

テンプレートはスクリプトから生成している。手で直さず、スクリプトを直して再生成する。

```bash
python3 scripts/gen_chart_templates.py   # charts/
python3 scripts/gen_qc7_templates.py     # qc7/ の Excel
python3 scripts/gen_pptx_templates.py    # qc7/ の pptx と n7/
```

必要なパッケージは `openpyxl` と `python-pptx`。

**フォントは資料テンプレートに合わせる。** 資料テンプレートがあるなら、
まずスタイルを読み出し、そのフォントで図テンプレートを作り直す。
図だけ別のフォントだと、資料に貼った瞬間に浮く。

```bash
python3 scripts/read_template_style.py ../../assets/templates/deck/<file>.pptx
python3 scripts/gen_chart_templates.py --font '<日本語フォント名>'
python3 scripts/gen_qc7_templates.py   --font '<日本語フォント名>'
python3 scripts/gen_pptx_templates.py  --font '<日本語フォント名>'
```

見た目の確認は次で行う。**PDF を経由しない**（日本語が文字化けする）。

```bash
python3 <slider-deck>/scripts/qa_render.py <file> -o qa
```
