# 回帰用の入力

**過去に壊れた場所を、次の改訂でまた壊さないために置いてある。**

`55_revise.md`「変種で壊れたら、制約を足すだけでなく検証にも足す」の受け皿。
**検査を緩めたら、必ずここを通す。** 緩めすぎて盲目になっていないかを見る。

```bash
python3 scripts/html2pptx.py scripts/regress/01_overlap_and_spill.html -o /tmp/r1.pptx --keep-coords --force
python3 scripts/fit_check.py check /tmp/r1.pptx
```

| ファイル | 出るべきもの | なぜ置いてあるか |
|---|---|---|
| `01_overlap_and_spill.html` | **重なり1件・溢れ1件** | 重なり判定を枠から文字の実占有域に変えたとき、本物まで出なくなる恐れがあった |
| `05_svg_scale_cases.html` | **3本とも top=300px**（viewBox あり／CSS の height 無し／属性で寸法） | **座標の値を見ずに「8本入った」と報告した。**全部スライド外でも本数は合う。書き方を変えると倍率が壊れる |
| `04_chart_and_colwidth.html` | **縦棒1系列・折れ線2系列・列幅600:200:400** | 絵から数字は戻せない。数を渡さないと、受け取った側が直せない図になる。列幅を移さないと項目名の列が折り返す |
| `03_svg_lines.html` | **コネクタ8本（破線1・矢印1・色5種）＋パレート図はテンプレート案内** | 作図の線を写さないと、特性要因図・系統図・アローダイアグラムが「文字が浮いているだけ」になる。逆に、数値グラフまで写すと数字を直せない画像になる |
| `02_background_flex_multislide.html` | **2枚・塗り3色・横中央・ネイティブの表・svg のテンプレート案内** | `background:` ショートハンドの塗りが全部消え、flex の主軸を取り違えて横の中央ぞろえが効かず、複数枚の HTML を1枚に切り詰めていた |

**「出るべきもの」が出なくなったら、その改訂が検査を盲目にしている。**

**数だけ見ない。値を見る。** 「8本入った」は、8本ともスライド外でも成り立つ。
座標・寸法・色まで突き合わせる。
件数が増えた場合も調べる。誤検出を足した可能性がある。

## 通すときの注意

**5枚を同じ出力先に書かない。** `html2pptx.py` は既存ファイルを上書きしない
（`--force` が要る）ので、2枚目以降が失敗し、**回帰が壊れたように見える。**
実際にそれで「5枚中1枚」と誤報した。**出力名は見本ごとに分ける。**

```bash
for f in scripts/regress/0*.html; do
  python3 scripts/html2pptx.py "$f" -o "/tmp/reg_$(basename "$f" .html).pptx"
done
```

## 06_nested_style_and_autofit.html

**実案件で18枚中12枚が崩れた型を、まとめて押さえる見本。**

| 見るところ | 期待 | 壊れると |
|---|---|---|
| `spAutoFit` が**無い**こと | 0件 | 折り返した枠が下へ伸び、隣・下の要素と重なる |
| `wrap="none"` が**有る**こと | 1件以上 | `nowrap` が中の `<p>` にあると折り返し、丸バッジが枠外へこぼれる |
| 文字サイズに**既定の18pt が無い**こと | 8〜12pt | 体裁が `<span>` 側だけにあると既定に落ち、折り返しが変わる |
| 表セルの `marL/marR` | **57150**（CSS の 6px） | 既定 91440（0.1in）だと収まる文字が折り返し、行が伸びる |
| 記号を含む run の `latin` | **和文書体** | `→ ① ◎ ℃` が欧文書体に渡ると字幅が変わる |
| 表セルの塗り | **`008096` / `EBEAE8`** | 既定に任せると、ヘッダ帯も交互塗りも白や薄グレーに落ちる |
| **入れ子に flex がある枠**の縦位置 | **MIDDLE** | 外側だけ見ると中央ぞろえを見落とし、**高い枠ほど上寄せが目立つ** |

```bash
python3 scripts/html2pptx.py scripts/regress/06_nested_style_and_autofit.html -o /tmp/f06.pptx
python3 scripts/probe_pptx.py /tmp/f06.pptx
# 塗りと縦位置は probe に出ないので、python-pptx で cell.fill / vertical_anchor を見る
```

**unzip しない。**`probe_pptx.py` が上の観点を1つの表で出す。

## 07 — 整列と、箱で描いたグラフ

| 見るところ | 期待 | 壊れると |
|---|---|---|
| `--relayout` を付けたときの重なり | **0件** | 写した座標のままでは、伸びた枠が下・隣と重なる |
| 帯（上端・高さ56px） | **動かない** | 器が崩れる。ロゴや見出しの位置が毎回変わる |
| 大きさの違う塗り箱3つ | **警告1件** | 数字の入らないグラフを、気づかず提出する |
| **同じ大きさの札3枚** | **警告が出ない** | 誤検出。毎回「これは違います」と説明することになる |
| `--keep-coords` を付けたとき | **重なりが出る** | 既定を変えたときに、写す経路が壊れていても気づけない |

```bash
python3 scripts/html2pptx.py scripts/regress/07_relayout_and_boxchart.html -o /tmp/f07.pptx
python3 scripts/fit_check.py check /tmp/f07.pptx   # 指摘 0 件
```

## 08 — 本文枠の中の図と表

**実案件の HTML は、図も表も本文枠（`body-area`）の中に置く。**

| 見るところ | 期待 | 壊れると |
|---|---|---|
| グラフ | **1件入る** | 直下しか見ないと、**図が1つも入らず警告も出ない** |
| 表 | 1件入る | 表だけ拾って図を落とす（同じ枠に両方あるとき） |
| 高さの無い枠がある枚 | **位置を写し、その旨を出す** | 動かした枠と動かせない枠が重なる |

```bash
python3 scripts/html2pptx.py scripts/regress/08_nested_chart_and_table.html -o /tmp/f08.pptx
# 「グラフにした」「表を…ネイティブの表に」「整列: 高さの書かれていない枠」の3行が出る
```

## 不具合を直したら、ここに見本を足す ★

**見本が無い直しは、次の改訂で静かに戻る。**
実績: 見つかった不具合の型が、既存の見本のどれにも入っていなかった。
検査を緩める改訂を当てても、**通ってしまうので気づけない。**

| 足す条件 | 足さなくてよい条件 |
|---|---|
| 検査の**判定**を変えた（見逃す／誤検出する側どちらも） | 文言・体裁だけの直し |
| 変換の**出力**が変わった（寸法・書体・塗り・枚数） | 道具の使い方の説明を足しただけ |

足し方は、いちばん小さい HTML を1つ置き、**何が出るべきか**をこの
README に1行書く。**「出るべきものが出ない」ことを検知するのが目的**なので、
直す前の入力をそのまま使う。
