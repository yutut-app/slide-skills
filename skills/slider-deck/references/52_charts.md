## グラフは Excel で作って貼る ★

**提出先で数字を Excel で直せるようにする。**

```bash
# 1. HTML の図から .xlsx を起こす（どの環境でも動く）
python3 scripts/chart_xlsx.py deck/deck.html -o deck/charts

# 2. 貼る前に、対応づけを確かめる（**どの環境でも動く**）
python3 scripts/chart_xlsx.py --paste --dry-run deck/charts deck/deck_rev1.pptx

# 3. Excel のグラフを pptx に貼る（**Windows + Excel + PowerPoint**）
python3 scripts/chart_xlsx.py --paste deck/charts deck/deck_rev1.pptx
```

貼る位置は `geometry.json` に控えてある（元の図の座標）。
**控えが無い図は中央に入ったままになり、その旨を出す。**黙って置かない。

**数は推測しない。**出どころは `data-values` → 図の中の「ラベル 数値」の順で、
**どちらも読めなければ作らず、読めなかった図として報告する。**
絵から元の数字は戻せない。**目分量で入れると、間違いが資料に残る。**

貼り付けは**図形として貼る**（リンクにしない）。リンクにすると、
受け取った側で .xlsx の場所が変わったときに開けなくなる。

**グラフは、HTML の書き方で結果が変わる。** ★

| HTML の書き方 | pptx で何になるか |
|---|---|
| `<svg data-chart="..." data-values="...">` | **ネイティブのグラフ。中にワークシートを持つ**ので、受け取った側が数字を直せる |
| `<div>` を並べて棒に見せている | **ただの塗り図形。**中に数字が無く、**PowerPoint でも Excel でも直せない** |
| 数の無い作図（線と文字） | コネクタに写す。これは正しい姿 |

後者は変換器が見つけて警告を出す。**絵は似ているので、絵だけ見ても気づけない。**
直すのは配布元。`data-chart` と `data-values` を足してもらう。
**別に .xlsx を添える必要はない。**グラフ自身がワークシートを持っている。

**HTML に入っているものを、そのまま写せるとは限らない。**
分かれ目は「**絵から元の情報が戻せるか**」。

| 種類 | どうするか | なぜ |
|---|---|---|
| **表** | **変換器がそのまま作る**（ネイティブの表） | 数字が残り、受け取った側が直せる |
| **作図**（特性要因図・系統図・アローダイアグラム） | **変換器が線を写す**（コネクタ） | 線を写せば編集できる図形になる |
| **数値グラフで、HTML に数が書いてある** | **変換器がそのまま作る**（ネイティブのグラフ） | **中にワークシートを持つ。**PowerPoint の中で数字を直せる |
| 数値グラフで、**絵としてだけ描いてある** | **作れない。**HTML に数を足してもらう | 絵からは元の数字が戻らない |

**手で作るのは、最後の手段。**

HTML にこう書いてあれば、**変換器がネイティブのグラフにする。手作業はいらない。**

```html
<svg data-chart="column" data-labels="A,B,C" data-values="62,18,11"
     data-series="不良件数"></svg>
```

対応する型は14種（棒・横棒・積み上げ・折れ線・円・ドーナツ・面・レーダー・散布）。

**数が書かれていない図に出会ったら、Excel で作る前に配布元へ戻す。**
`data-chart` と `data-values` を HTML に足してもらえば、次の変換から自動で入る。
**手で作ると、次に HTML が直ったときにもう一度手で作ることになる。**

どうしても手で作るなら、雛形は `assets/templates/charts/` `qc7/`、
型の選び方は `assets/templates/INDEX.md`。

```
グラフの合格条件:
- [ ] 数値が HTML の表・data 属性と一致しているか
- [ ] 軸・単位・凡例が HTML の記載と合っているか
- [ ] 主旨が、その枚のメッセージと合っているか
- [ ] **元の Excel も一緒に渡せるか。**受け取った側が数字を直せる
```

**絵柄は同じでなくてよい。「数値が違う」だけが不合格。**

**作図の線が1本も入っていなければ、変換の不具合を疑う。**
黙って消える型の事故が実際に起きた（`docs/feedback.md` の原因 C）。
**本数を数え、スライドの外に出ていないかを見る。**
