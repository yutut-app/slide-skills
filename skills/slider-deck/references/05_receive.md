# 05_receive — テンプレートを作り直すとき・会話で受け取ったとき

**`SKILL.md` から切り出した手順の細部。**本体の該当箇所から読みに来る。

## 無いとき・食い違うときだけ、作り直す

**手元のものを黙って上書きしない。**置いてあるものが正しいのがふつう。
作り直すのは、**置いていない機械で使うとき**か、
**指紋が食い違って、受け取った HTML のほうが新しいと分かったとき。**

```bash
python3 scripts/gen_template.py <受け取った>/print.html -o assets/templates/deck/<名前>
```

資料の HTML は**テンプレートと同じ `<style>` を持っている**ので、
px→pt の係数・スライド寸法・共通パーツの座標・配色・文字サイズが取れる。

**使うたびに作り直す。** 手で写すと、配布元がテンプレートを直したときに
古いまま残る。**毎回 HTML から作れば、受け取ったものと必ず一致する。**

| | |
|---|---|
| 係数の出どころ | HTML の `<meta name="px-per-pt">`。無ければ `--px-per-pt` |
| **どちらも無いとき** | **作らない。**既定で作ると、狂った寸法を正しいものとして固定する |

**作ったら、変換して寸法を確かめる。**
出力の「スライドサイズ」が、元 PPTX と同じ pt になっていること。

**ロゴは作り直せない。** `images/` は HTML が参照しているファイルを
**写すだけ**で、画像そのものが届いていなければ復元できない
（`n 件が見つからない` と出る）。**手元のテンプレートの `images/` を使う。**

```bash
python3 scripts/qa_render.py --probe
```

**道具が無いなら、無いと報告する。** 「検査した」と書かない。

## 会話に貼られた HTML を受け取ったとき ★

**ファイルで渡らないことがある。**長すぎて送れない、共有の手段が無い、など。
そのときは**会話に貼られた中身をそのままファイルに書き出してから始める。**

```bash
# 貼られた中身を保存する。**ここから先は、いつもの手順と同じ**
cat > deck/deck.html <<'EOF'
（貼られた HTML をそのまま）
EOF
```

| やること | 理由 |
|---|---|
| **まずファイルに落とす** | 道具はファイルを受け取る。会話の中身は検査できない |
| **`.slide` の数を数える**（`pptx_diff_html.py` が出す） | 途中で切れて届くことがある。**枚数が合わなければ止める** |
| **テンプレート一式が別に要る** | 貼られるのは中身だけ。**寸法とロゴは付いてこない** |
| 係数を確かめる | `<meta name="px-per-pt">` が無ければ、手元のテンプレートから採る |

**切れたまま変換しない。**足りない枚数は、**足りないと報告する。**
