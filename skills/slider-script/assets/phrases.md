# 話さない言い回し（検査語の台帳）

`script_check.py` が既定で読む。**`slider-craft` の `ledger_check.py --terms` からも同じ台帳を指す（列名「使わない語」を共有する）。**
2箇所に別々の一覧を置くと、片方だけ更新されて食い違う。

**どれも「禁止」ではなく「その言い方になっていたら見直す」。**
案件固有の語は、この表をコピーして `--phrases <自分の台帳>` で差し替える。
