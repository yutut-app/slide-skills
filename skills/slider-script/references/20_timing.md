# 20_timing — 持ち時間の割り当て

手順1で読む。**持ち時間は発表ごとに変わる。毎回聞く。**

## 1. 見積もりの基準

| 項目 | 目安 | 根拠 |
|---|---|---|
| 話す速さ | **1分あたり 300字**（日本語） | ゆっくりめ。緊張すると速くなるので、遅い側で見る |
| 1枚あたり | 持ち時間 ÷ 枚数 が基本 | 下の配分で重みを付ける |
| 質疑 | **持ち時間に含めない。**別に取る | 含めると、話す時間が足りなくなる |

**字数は目安であって、上限ではない。**超過はそのまま「話し切れない」を意味する。

## 2. 枚ごとの重み

**均等に割らない。**枚によって話す量が違う。

| 枚の種類 | 重み | 理由 |
|---|---|---|
| 表紙・目次・区切り | **0.3** | 数秒で渡す |
| 結論・提案 | **1.5** | ここで聞き手が判断する |
| 図・表が主体 | 1.2 | どこを見るかの案内が要る |
| 本文だけ | 1.0 | 基本 |
| 付録・配布のみ | **0** | **話さない。**台本に `**話さない**` と書く。尺に数えない |

```
1枚の字数 = 持ち時間(分) × 300 × その枚の重み ÷ 重みの合計
```

## 3. 割り当ては、書く前に表で見せる

| 枚 | 種類 | 重み | 目安の字数 |
|---|---|---|---|
| 1 | 表紙 | 0.3 | 90 |
| 2 | 目次 | 0.3 | 90 |
| 3 | 結論 | 1.5 | 450 |

**この表を承認してもらってから書き始める。**書いた後で持ち時間が違うと、全枚を直す。

## 4. 入りきらないとき

**縮めて詰め込まない。**早口は、聞き手が理解できない。

| 手 | 何を失うか |
|---|---|
| **枚を付録へ回す**（推奨） | 話の流れは保てる。聞かれたときだけ開く |
| 図の説明を削る | 図を出した意味が薄れる |
| つなぎを削る | 話が飛んで聞こえる。**最後に削る** |
| 結論を削る | **やらない** |

**どれを落とすかは発表者に聞く。**こちらで決めない（`SKILL.md` の承認ポイント）。

## 5. 実測は発表者の作業

**見積もりは当たらない。**書き終えたら、通しで声に出して読み、実際の時間を測る。

**測れるのは発表者だけ。**こちらは声に出せない。**「実測してください」とだけ書かない。**
何を測り、どう返すかまで書く。

```markdown
## 実測のお願い

1. `script.md` を上から通して、**声に出して**読む（黙読は速すぎて当てになりません）
2. 止めずに1回で読み、かかった時間（分）を教えてください
3. 読みながら詰まった枚があれば、その番号も
```

| 実測 ÷ 持ち時間 | すること |
|---|---|
| 1.1 倍を超える | 削る。下の順で |
| 0.8 倍を下回る | **足す。**早く終わるのも失敗。質疑が長くなる |
| その間 | そのままでよい |

**実測が返ったら、見積もりの速さを実測値に差し替える**（`--chars-per-minute`）。
以降の枚の割り当てが、その人の速さに合う。

## 6. 持ち時間が変わったとき

**よくある。**「30分と聞いていたが15分になった」で全枚が変わる。
**書き直す前に、削る順を示して承認を得る**（`SKILL.md` の承認ポイント）。

| 順 | 削るもの | 失うもの |
|---|---|---|
| 1 | **補足・付録へ回す枚** | ほぼ無い。聞かれたら開く |
| 2 | **同じことを繰り返している枚**（再掲・まとめの重複） | ほぼ無い |
| 3 | 図の説明の細かさ | 図を追う速さが上がり、置いていかれる人が出る |
| 4 | つなぎ | 話が飛んで聞こえる。**最後に削る** |

**削ってはいけないもの。**

- **各枚の「伝えること」。**これを削ると、枚が残っていても何も伝わらない
- 結論と、次にやること
- 数値の根拠（母数・期間・除いたもの）

**枚を減らすのが先、1枚の字数を薄めるのは後。**全枚を均等に薄めると、
どの枚も中身が足りない台本になる（**字数の検査は通るのに、薄いと言われる**）。
