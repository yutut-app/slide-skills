# 30_check — 聞き手の目で検査する

手順3で読む。**機械の検査（`script_check.py`）を通した後に行う。**

## 1. 役を確定する

**前の版も、直した経緯も、作る過程も知らない聞き手**として読む。
作り手と利用者は往復を重ねるうちに、前の版を前提に読むようになる。聞き手は知らない。

| 項目 | どこから取るか |
|---|---|
| 立場・前提知識 | 手順1で確定した聞き手 |
| 知っている用語 | **その人が日常で使う語だけ。**社内の略語は知らない扱い |
| 見ているもの | **スライドだけ。**台本も、前の版も見ていない |

## 2. 伝えることと本論を突き合わせる（**字数では分からない**）

**機械は字数しか見ない。**尺が目安に収まっていても、中身が薄いことはある。
**先にこれを行う。**言い回しの手直しは、中身が入ってからでよい。

| 見る点 | 落ちる例 |
|---|---|
| 手順2で合意した「伝えること」が、その枚の欄にあるか | 書き進めるうちに別の話にすり替わった |
| **本論が、その1つを説明しているか** | 伝えることに触れず、図の読み方だけ話している |
| **根拠が本論にあるか**（数・期間・母数） | 結論だけ言って、なぜそう言えるかが無い |
| 1枚で2つ以上言っていないか | 「伝えること」が2文になっている |

**合意した一覧と台本を、枚ごとに並べて見る。**片方だけ読むと、抜けに気づけない。

## 3. 通して読む

**枚ごとに読まない。上から通して読む。**断絶は、枚をまたいだところに出る。

| 見る点 | 典型 |
|---|---|
| **計算の飛び** | 途中の数字を言わずに結論の数字だけ言う（103件 → 「約6割」） |
| **定義前の用語** | 初出の略語・社内用語をそのまま話す |
| **枚の断絶** | 「次に」で急に別の話題に変わる。前の枚の結論を受けていない |
| 指示語 | 「これ」「その値」が何を指すか、音声で分かるか |
| 長すぎる文 | 息継ぎができない。読んでみて詰まるか |
| **作り手の言葉** | 工夫・試行錯誤・自己評価・手法の注意。**聞き手の関心事ではない** |
| **権限を超えた言い方** | 「合格とします」「決定します」を、決める権限が無い場で言う |
| **誇張・決まり文句** | やっていないことを、できる形にしたと言い換える |
| **立場の言い回し** | 「上から」「本部」が説明なしに出る。外の聞き手に通じない |
| **聞き手の関心とずれる** | 手順1で確定した場（実務の報告か、手法を教える場か）と合っていない |

## 4. 3つに仕分ける

| 分類 | どうするか |
|---|---|
| **台本で直せる** | 直す（言い回し・定義・つなぎ・尺） |
| **スライドに足りない** | **直さずに報告する。**台本で数字や根拠を足さない |
| **判断が要る** | 発表者に聞く（削る内容、言い切ってよいか、決める権限があるか） |

**機械が「要確認」で出したものは、ここで目で見る。**定義前の用語は、
言い回しを変えれば機械は通る。**通ったかどうかではなく、聞いて分かるかで決める。**

## 5. 報告の形

```markdown
## 台本の検査

検査: script_check  対象 18枚  指摘 3件  前提: 持ち時間=20分, 目安=1分300字

### 直したもの
| 枚 | 症状 | 直し |
|---|---|---|
| 6 | 「約6割」の根拠を言っていない（計算の飛び） | 62件÷103件と言ってから割合を言う形にした |

### スライドへ返す（直していない）
| 枚 | 足りないもの | なぜ台本で補えないか |
|---|---|---|
| 8 | 母数がスライドに無い | 台本で足すと、スライドと食い違う |

### 未対応
- 14枚目の用語「4M」を定義するか、聞き手が知っている前提にするか未決
```

**「未対応」を必ず書く。**書かないと、全部できたと受け取られる。
