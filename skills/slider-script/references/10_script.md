# 10_script — 台本の型と、話し言葉の規約

手順3で読む。

## 1. 台本は、スライドに書いていないことを話す

**聞き手はスライドを読める。**読めば分かることを声に出すと、聞き手は退屈し、
その間に考える時間を奪われる。

| スライドにあるもの | 台本で話すこと |
|---|---|
| 結論・数値 | **その数値をどう出したか。**どこから取り、何を除いたか |
| 図・表 | **どこを見てほしいか。**目の動かし方（左から、上位2つ） |
| 箇条書き | **なぜその順か。**並びの意味 |
| 次の枚の見出し | **前の枚とのつながり。**「ここまでが現状、ここからが対策」 |

**読み上げてよい例外は、キーメッセージだけ。**1枚に1回まで。

### 逆に、話さないこと

**この節が無いと、上の表は「話を足す」方向にだけ効く。**実績として、
つながりと根拠を足すつもりで、聞き手の関心から外れた話が積み上がった。

| 話さない | 例 |
|---|---|
| **聞き手が判断に使わない情報** | 「分からなくなったらこの表に戻ってください」 |
| 手法や資料の作り方 | 「母数のそろえ方は間違えやすい」「同じ形で並べないと比べられない」 |
| 一般論・教科書との違い | 「よくある教科書の並びとは1か所違います」 |
| 作り手の評価 | 「ここがいちばん効きました」 |

**判断の材料になるか**で決める。ならないものは、聞かれたときに答える。

## 2. 話すのは、事実と判断だけ

**「つながりと根拠を話す」は、作った過程を話すことではない。**
ここを取り違えると、聞き手の関心から外れた話が積み上がる。

| 話す | 話さない |
|---|---|
| **起きている事実**（何が、いくつ、いつ） | 資料を作るときに工夫したこと |
| **そこから何が言えるか**（判断） | 試行錯誤の経過（途中でどう変えたか） |
| **次に何をするか**（行動と期限） | 自己評価（効いた、うまくいった、いちばん） |
| 聞かれたら答える補足 | 作り手の作法（手法の注意点、一般論、教科書との違い） |

**やった事実と、作った過程は違う。**「現場で試した結果こうなった」は事実。
「作るときにこう置いた」は過程で、聞き手には要らない。

### 機械で拾う言い回し

`assets/phrases.md` に台帳がある。`script_check.py` が既定で読む。
区分は **作り手の工夫／自己評価／作り手の作法／権限を超える／誇張／立場の言い回し**。

- **権限を超える言い方をしない。**「合格とします」「決定します」は、
  その権限がある場でだけ言える。無い場で言うと、後で覆る
- **誇張しない。**実際にやったことを、やったとおりに言う。
  やっていないことを、できる形にしたと言い換えない
- **立場の言い回しを説明なしに使わない。**「上から」「本部」は外の聞き手に通じない。
  誰が、を名前か役割で言う

案件固有の語が増えたら、台帳をコピーして `--phrases` で差し替える。**規約だけでは守られない。**

## 3. 1枚の台本の型

```markdown
## 3. 不良の内訳

**伝えること**：不良の8割は上位2項目に集まっている。
**つなぎ**：前の枚で全体の件数を見たので、ここから内訳に入る。
**本論**：上位2項目で8割を占めています。
**見てほしい場所**：左の棒グラフの上位2本。累積線が80%を超えるところ。
**次へ**：この2項目に絞って、原因を見る。
**想定質問**：それ以外の項目は見ないのか。→ 件数が少ないため、今回は対象外。
```

| 欄 | 書くこと | 無いとどうなるか |
|---|---|---|
| **伝えること** | **この枚で伝える、ただ1つのこと。1文** | 説明が増え、何が言いたいか残らない |
| つなぎ | 前の枚から、なぜこの枚に来たか。**前の枚に出た語を使って始める**（「先ほど挙げた要因を」「同様に」） | 話が飛んで聞こえる。**1枚ずつ独立した説明になる** |
| 本論 | **「伝えること」1つを説明する。**数値はスライドにあるものだけ | スライドと食い違う |
| 見てほしい場所 | 図のどこを見るか | 聞き手は図を探している間、話を聞いていない |
| 次へ | 次の枚への渡し | 枚が変わるたびに話が切れる |
| 想定質問（任意） | **聞かれたら出す。こちらからは言わない** | 本編が長くなる。無いと質疑で詰まる |

### 声に出す欄は、そのまま読める文で書く

**台本は本番で読む。**欄の見出しは読まない。
**つなぎ → 本論 → 見てほしい場所 → 次へ を上から読めば、そのまま話せる**ようにする。

| 欄 | 声に出すか |
|---|---|
| 伝えること | **出さない。**書く人のための欄 |
| つなぎ・本論・見てほしい場所・次へ | **出す。**この4つが本番で読む本文 |
| 想定質問 | **出さない。**聞かれたときだけ見る |

- **1文1行。**1行に2文を入れない。読むときに息継ぎの位置が分からない
- **要約した書き方をしない。**「結果です」ではなく、声に出して通る文にする
- **数値には単位を付ける。**「23.4」ではなく「1万点あたり23.4件」。
  1度言っただけでは聞き手は覚えていない
- **図は色と位置で指す。**「横の赤い点線」「左の棒グラフの上位2本」

**1枚で伝えるのは1つ。**「伝えること」が2文になったら、話が2つある。
枚を分けるか、片方を捨てる。**説明を足すほど伝わらなくなる。**

**「伝えること」以外の4欄をすべて埋める。**埋まらない枚は、枚そのものが要らない。
想定質問は声に出さないので、尺には数えない。

### 話さない枚

配布のみの枚、付録、区切りの枚は、本文に `**話さない**` と書く。

```markdown
## 18. 付録：測定の手順

**話さない**（配布のみ。聞かれたら開く）
```

欄の必須と尺の集計から外れる。**空欄のまま置かない。**なぜ話さないかが残らない。

## 4. 話し言葉の規約

| 規約 | 理由 |
|---|---|
| **1文を短く（目安40字）** | 息継ぎができない文は、読むと詰まる |
| **文体は読む人で決める** | **自分が読むなら問わない**（混在してよい）。**他人が読むなら敬体にそろえる** |
| **数字は読み方を書く**（1/3 → 3分の1） | 読み間違える |
| **初出の用語は、その場で定義する** | 聞き手は後の枚を見ていない |
| 指示語を避ける（これ・それ） | 音声では何を指すか分からない |
| 言い切る | 「〜と思われます」は、聞き手の判断材料にならない |

**自分が話す用でも、数値と固有名詞だけは文字で書く。**そこだけは間違えると戻せない。

## 5. 書く順番

**1枚ずつ、順に書く。**全枚を一度に書くと、枚のつながりが切れる。

1. **手順2で合意した「伝えること」を、その枚の欄に写す**
2. その枚のスライドを見る（**文字だけでなく、図も見る**）
3. つなぎ → 本論 → 見てほしい場所 → 次へ、の順に埋める。
   **本論は「伝えること」1つを説明する**
4. 声に出して読む長さを見積もる（`20_timing.md` の目安）

**書き終えた枚から検査に回さない。**通しで読まないと、断絶は見つからない。
