## 1. 置き場所

```
slide-skills/                     ← リポジトリをクローンした場所
├── assets/templates/deck/        ← ここ。3つのスキルが同じ場所を見る
│   ├── <テンプレ名>/             **HTML 一式**（template-manifest.md を含む）
│   └── <汎用のもの>.pptx         生成物。同梱していない
└── skills/
    ├── slider-craft/             資料を作るスキル
    ├── slider-deck/              pptx にするスキル
    └── slider-reskin/            このスキル
```

**テンプレートを2箇所に置かない。** 置くと必ず食い違い、
どちらが正か分からなくなる。

### 2種類ある。用途が違う

| 置くもの | 形 | 使う道具 |
|---|---|---|
| **HTML テンプレート一式** | `<テンプレ名>/` ディレクトリ。`template-manifest.md` を含む | **載せ替え（このスキル）**と、資料作成の土台 |
| .pptx テンプレート | ファイル1つ | `<slider-craft>/scripts/make_html.py`（経路B）だけ |

**このスキルが一覧に出すのは前者だけ。** `.pptx` は載せ替えに使えない。

**px→pt の係数は `template-manifest.md` にある。**
これが無いとスライド寸法が狂う（`<slider-craft>/references/48_html.md`）。
**HTML だけ渡して manifest を渡さない、が最も多い抜け。**

### 別の機械で使うとき ★環境の決めごと

**置き場所は OS によらず同じ相対位置。**

```
Windows:  <クローン先>\assets\templates\deck\<テンプレ名>\
macOS:    <クローン先>/assets/templates/deck/<テンプレ名>/
```

**クローン直後には `assets/templates/deck/` が存在しない**（git に入れていない）。
**受け取った側が自分で作り、渡されたテンプレートのフォルダを丸ごと置く。**

別の場所に置きたいなら `SLIDE_TEMPLATE_DIR` を向ける。

```
Windows (PowerShell):  $env:SLIDE_TEMPLATE_DIR = "D:\templates"
macOS:                 export SLIDE_TEMPLATE_DIR=~/templates
```

**置いたら、一覧に出ることを確かめてから始める。**
名前が同じでも中身が違うことがあるので、
**指紋を突き合わせる**（`<slider-craft>/references/49_handoff.md`）。

## 1-2. 実物の .pptx に合わせる

**HTML テンプレートの見た目は、100% HTML 側で決まる。**
変換は python-pptx の空ファイルを土台にするので、
**実物の .pptx のマスターもテーマもロゴも、出力には一切入らない**
（`<slider-deck>/scripts/html2pptx.py` の `build_absolute`）。

だから「実物のテンプレートに合わせる」とは、
**実物の中身を HTML テンプレート側に取り込むこと。**
.pptx をどこかに置いて変換時に読ませる、ではない。

### 実物を置く場所

```
assets/templates/deck/<テンプレ名>/source.pptx    ← 実物
```

**HTML 一式と同じフォルダに置く。** 別の場所に置くと、
どの HTML がどの実物から来たのか分からなくなる。

| なぜここか | |
|---|---|
| 一覧に出ない | `reskin_html.py` が見るのは `*.html` だけ |
| git に入らない | このフォルダごと `.gitignore` の対象 |
| **指紋が変わらない** | 指紋は `*.html` / `template-manifest.md` / `images/` を見る |

`template-manifest.md` の `source_pptx:` 欄が、この位置を指す。

### 取り込む手順

**1. 画像を取り出す。**

```bash
python3 <slider-craft>/scripts/extract_assets.py <テンプレ>/source.pptx -o /tmp/assets
```

画像ごとに大きさと**使われ場所**（`master` / `layout:<n>` / `slide:<n>`）が出る。
**マスターかレイアウトで使われている大きなものが、ふつうロゴ。**
**決め打ちしない。**表を見て人が選ぶ。

```bash
cp /tmp/assets/<選んだもの>.png <テンプレ>/images/logo.png
```

**2. 座標・文字・書体の差を出す。**

```bash
python3 <slider-deck>/scripts/pptx_diff_html.py <テンプレ>/source.pptx <テンプレ>/print.html
```

**3. 差を HTML テンプレートに反映する。** 直すのは HTML。
**`source.pptx` を直さない。**実物は読むだけのもので、正本ではない。

**4. 指紋を取り直し、受け取る側と突き合わせる。**

```bash
python3 <slider-craft>/scripts/handoff.py <テンプレ> --fingerprint
```

### 取り込めないもの

| | なぜ |
|---|---|
| **スライドマスター・レイアウト・テーマ** | 変換の土台は空のファイル。**PowerPoint で新しいスライドを挿すと、会社のレイアウトは出ない** |
| **図形で描かれたロゴ** | 画像ではないので `extract_assets.py` では出ない。**PowerPoint 上で見て確かめる** |

**「合わせた」と報告する前に、絵で見比べる。**
実物を PowerPoint で開いた絵と、変換した pptx の絵を並べる。

### 資料を渡している最中は差し替えない

**正本の HTML が相手の手元にある間に、こちらでテンプレートの画像を替えない。**
指紋が食い違い、相手は「テンプレートがずれている」と止まる。
**戻ってきてから替える。**

---

### ここは git に入っていない ★環境の決めごと

| 種別 | なぜ入れないか |
|---|---|
| 利用者が置いたもの | 置くかどうかは利用者が決める |
| **汎用のもの** | **`<slider-craft>/scripts/gen_deck_templates.py` の生成物。**生成できるものを git に置かない |

**空でも異常ではない。** 汎用テンプレートが要るなら、その場で生成する。

```bash
python3 <slider-craft>/scripts/gen_deck_templates.py
```

**一覧が空のときに「テンプレートが無い」で止めない。**
生成できると述べ、生成してよいか聞く。

探索の順は次のとおり。上が優先。

| 順 | 場所 |
|---|---|
| 1 | 環境変数 `SLIDE_TEMPLATE_DIR` |
| 2 | リポジトリ直下の `assets/templates/deck/` |
| 3 | スキル内の `assets/templates/deck/`（スキルを単独で置いた場合の保険） |

どこを見ているかは、一覧を出せば分かる。

```bash
python3 scripts/reskin_html.py --list
```

**この順は `reskin_html.py` の `template_dir()` と同じにする。**
実際に、ここには `SLIDE_TEMPLATE_DIR` を1番目に書きながら、
**実装が読んでいなかった。**別の機械で規約どおりにしても効かない状態だった。

## 1-3. マニフェストに書くもの ★

`template-manifest.md` は**テンプレートの仕様書**。
**ここが空だと、毎回 HTML を読んで座標を実測することになる**（実際にそうなった）。

```markdown
---
template_name: <名前>
slide_size: <幅>x<高さ>px (元PPTX <幅>x<高さ>pt, 1pt = <係数>px)
---

## テンプレート種別一覧
| ファイル名 | 種別 | 説明 |

## 共通パーツの座標 ★
| 要素 | class | left | top | width | height | 見た目 |
|---|---|---|---|---|---|---|
| フッター帯 | `footer-bar` | 0 | 696.4 | 1175 | 23.6 | 塗り <色> |
| ページ番号 | `footer-page` | 1175 | 696.4 | 105 | 23.6 | 塗り <色> |
| ヘッダーロゴ | `header-logo` | … | … | … | … | 画像 |

## 配色
| 用途 | hex | テーマ名 |

## 文字サイズ
| 要素 | pt | px |
```

**共通パーツの座標を必ず入れる。** 毎枚に出る要素なので、
**引き継ぎでも、載せ替えでも、md からの組み立てでも、毎回要る。**

| 書く | 書かない |
|---|---|
| **class 名**（差し替えの鍵になる） | 資料ごとの文言 |
| 座標・大きさ・色・文字サイズ | 手元の絶対パス・利用者名 |
| px→pt の係数と、その出どころ | |

**`source_pptx` に手元の絶対パスを書かない。**
利用者名が入り、テンプレートを配ったときに相手に見える（実際に残っていた）。

## 2. テンプレートを足す

**`.pptx` か `.potx` をフォルダに置くだけ。** 名前は変えなくてよい。
一覧にはファイル名がそのまま出るので、**用途が分かる名前**にしておくと選びやすい。

PowerPoint で開いたままだと `~$<名前>.pptx` というロックファイルができるが、
一覧からは自動で除外される。

### 置いた後にやること

1. 一覧に出るか確かめる（`python3 scripts/reskin_html.py --list`）
2. スタイルを読み出す（[3](#3-テンプレートを調べる)）
3. 図のテンプレートをそのフォントに合わせて作り直す（[5](#5-図のテンプレートを合わせる)）

### git に入れるかどうか

**利用者が置いたテンプレートを、確認せずに commit しない。**
リポジトリに入れてよいかは利用者しか判断できない。

| 選択 | 意味 |
|---|---|
| commit する | 別の機械からも使える |
| commit しない | 追跡されない。保全は別に考える |

commit しない場合は `.gitignore` に個別に書き、**その旨を利用者に伝える。**
「保存した」とだけ言うと、バックアップされていると誤解される。

## 3. テンプレートを調べる

```bash
python3 scripts/read_template_style.py <テンプレート>.pptx
```

出るもの。

| 項目 | 使いどころ |
|---|---|
| スライドサイズ | 差し替え元とサイズが違うと図形が縮む |
| テーマのフォント（欧文 / **日本語 ea**） | 図のテンプレートを合わせるときに使う |
| 実際に使われているフォント | テーマと食い違うことがある |
| レイアウトごとのプレースホルダと文字サイズ | 割付の妥協が起きる理由が分かる |
| テーマの配色 | 色の置換の対応表になる |

**日本語フォントは `ea`（East Asian）に入る。** `latin` だけ見ると英字用の指定しか
取れず、日本語が何で表示されるか分からない。

## 4. 1つも無いとき

汎用のものを作れる。**利用者のテンプレートが手に入るまでの土台。**

```bash
python3 <slider-craft>/scripts/gen_deck_templates.py
```

| 名前 | 用途 |
|---|---|
| `00_汎用-標準` | 報告・提案資料の既定。濃紺を主役にした4色構成 |
| `01_汎用-モノクロ` | 白黒印刷・コピー向け。色でなく濃淡で差を付ける |

**スライドマスターとレイアウトの構成は既定のまま変えていない。**
レイアウトを自作すると、利用者が置くテンプレートとの互換が取れなくなるため。
変えているのはテーマのフォントと配色、スライドサイズ（16:9）だけ。

## 5. 図のテンプレートを合わせる

`slider-craft` が持つグラフ・QC7・新QC7のテンプレートは、**資料テンプレートと
同じフォントで作り直す。** 図だけ別のフォントだと、貼った瞬間に浮く。

```bash
cd ../slider-craft
python3 scripts/gen_chart_templates.py --font '<日本語フォント名>'
python3 scripts/gen_qc7_templates.py   --font '<日本語フォント名>'
python3 scripts/gen_pptx_templates.py  --font '<日本語フォント名>'
```

フォント名は [3](#3-テンプレートを調べる) の「本文用・日本語(ea)」を使う。
